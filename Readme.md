## Paper

This repository contains the official implementation of **AdaPPA: Adaptive Position Pre-Fill Jailbreak Attack Approach Targeting LLMs**, published at **ICASSP 2025**.

AdaPPA investigates jailbreak vulnerabilities in large language models and introduces an adaptive position pre-fill approach to evaluate their safety robustness.

📄 [Paper (IEEE Xplore)](https://ieeexplore.ieee.org/document/10890715) | [arXiv](https://arxiv.org/abs/2409.07503)
